# 使用说明

面向使用者的操作手册。安装包怎么装、装完怎么用、出问题去哪看，都在这里。

---

## 一、安装

### 图形界面安装

双击 `DshManager-Setup-1.9.7.exe`。

1. 会弹出 UAC 提权确认（安装是机器级的，要写 `C:\Program Files`）
2. 按向导下一步 → 安装
3. 结束时可以勾选「立即启动 鲸鱼娘 · DeepSeek Harness 管理面板」

默认安装位置：`C:\Program Files\DshManager`

### 静默安装

适合脚本化部署：

```powershell
# 默认安装（C:\Program Files\DshManager）
DshManager-Setup-1.9.7.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

# 自定义安装目录
DshManager-Setup-1.9.7.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR="D:\Tools\DshManager"
```

常见参数：

| 参数 | 作用 |
| --- | --- |
| `/VERYSILENT` | 完全静默，不显示任何界面 |
| `/SILENT` | 静默但显示进度条 |
| `/SUPPRESSMSGBOXES` | 抑制所有消息框，一律取默认答复 |
| `/NORESTART` | 安装后不自动重启系统 |
| `/DIR="路径"` | 指定安装目录 |
| `/LOG="文件"` | 把安装过程写入日志（**排查安装失败时最有用**） |
| `/NOICONS` | 不创建开始菜单项 |

> 桌面快捷方式：安装包默认**不**创建。需要的话从开始菜单把「鲸鱼娘 · DeepSeek Harness 管理面板」拖到桌面。

## 二、第一次运行

打开面板后，首页顶部是运行状态区。第一次使用建议按这个顺序：

1. **确认 dsh 位置。** 如果面板没自动找到你的 dsh，在首页「安装位置」里手动指定
   （即 `node_modules\@deepseek-ai\dsh` 所在目录，或 npx 缓存里的那份）。
2. **点「启动」。** 面板会拉起 dsh 服务并用你配置的端口（默认 `3080`）监听。
3. **点「打开面板」。** 用默认浏览器打开网页面板。

首页会实时滚动 dsh 的日志，出问题先看这里。

### 端口被占用怎么办

首页状态里能看到端口占用情况。如果端口被别的进程占了：

- 换个端口：**配置**页里改 `Port`
- 或者点「终止外部实例」，把不是本面板拉起的那个 dsh/node 进程结束掉

## 三、各页面怎么用

### 配置

以表单方式读写 `~/.dsh/settings.yaml`。

- 保存前会**自动备份**（带时间戳，最多保留 20 份）
- 写盘是**行级最小改写**，你的注释、未知字段、行尾注释都会被保留
- 如果 `settings.yaml` 在你停留期间被外部程序（dsh 自身、编辑器）改过，保存会**拒绝执行**
  并提示你先点「重新加载」——这是防止把对方的改动整段覆盖掉

### 插件

左侧是插件市场，按下载量排序，能搜、能看版本与描述。右侧是已装列表。

- 安装：在顶部输入框填包名（多个包用空格分隔），回车
- 卸载：已装列表里点对应条目的卸载

安装规格会被校验：包名只允许字母、数字与 `. _ - ~ /`，版本只允许字母、数字与 `. - + _ ~ ^ * >`。
**任何一条不合法就整批拒绝**，不会出现「装了一半」的情况。

### 记忆库

编辑长期记忆文件（默认 `AGENTS.md`）。

- 「项目作用域目录」用来隔离不同项目下的记忆；输入有 400ms 防抖，不会边打字边写盘
- 每次保存前自动备份，备份保留最近 10 份
- **备份失败时不会继续覆盖**（会明确报错），避免在无备份状态下写掉你的记忆

### 人格

管理人格模板（agent preset）。

- 删除是**可恢复**的：文件被移动到回收目录而不是直接抹掉
- 模板 id 有字符集约束，防止路径穿越

### 文件

只读浏览 dsh 数据目录，最多递归两层，用于快速找文件。

### 聊天

本地关键词匹配的鲸鱼娘对话，带表情包。**不联网**。

## 四、数据在哪 / 怎么卸载

| 内容 | 位置 |
| --- | --- |
| 面板设置、记忆库、人格 | `%LOCALAPPDATA%\DshManager\Data` |
| 内置 Node 运行时（约 2000 个文件） | `%LOCALAPPDATA%\DshManager\runtimes` |
| 表情包 | `%LOCALAPPDATA%\DshManager\Stickers` |
| 面板日志 | `%LOCALAPPDATA%\DshManager\logs` |
| dsh 自身配置 | `%USERPROFILE%\.dsh` |

### 卸载

**设置 → 应用 → 已安装的应用 → 鲸鱼娘 · DeepSeek Harness 管理面板 → 卸载**，
或开始菜单里的「卸载」项。

卸载会自动：

1. 按 **PID** 结束面板进程（不是按映像名，不会误杀同名程序）
2. 删除 `C:\Program Files\DshManager`
3. 清理 `%LOCALAPPDATA%\DshManager` 下的 Data / Stickers / runtimes / logs

> 如果同一台机器上有**多个 Windows 用户**都用过面板，卸载只清理当前执行卸载的那个用户
> 名下的数据。其他用户的数据需要各自清理。
>
> 想保留自己的设置和记忆库？卸载前先把 `%LOCALAPPDATA%\DshManager\Data` 整个拷走。

## 五、从源码构建

```powershell
# 需要 .NET SDK 8.0+
dotnet --list-sdks

# 构建 + 测试
dotnet build DshManager.sln -c Release
dotnet test  DshManager.Tests/DshManager.Tests.csproj -c Release

# 发布 + 打包安装包（需要已安装 Inno Setup 6）
pwsh -File tools/build-installer.ps1
```

打包脚本 `tools/build-installer.ps1` 会做这几件事：

1. 校验 `DshManager.csproj` 的 `<Version>` 与 `installer/DshManager.iss` 的 `#define AppVersion`
   **是否一致**，不一致直接报错退出（防止打出「文件名与程序属性页版本对不上」的包）
2. `dotnet publish` 自包含 win-x64 到中转目录 `C:\dshpub`，再整体拷回仓库 `publish\`
3. 调 ISCC 编译 `installer/DshManager.iss`，产物落在 `installer/output/`

参数：`-SkipPublish`（复用已有 `publish\`）、`-StageDir`（换中转目录）、`-OutputDir`（换产物目录）。

### 关于版本号

版本号有**唯一真源**：`DshManager/DshManager.csproj` 里的 `<Version>`。
`installer/DshManager.iss` 顶部的 `#define AppVersion` / `AppVersionQuad` 是它的副本，
**改一处必须改另一处**（打包脚本会替你检查）。`README` 与安装包文件名也跟着走。

## 六、排查问题

| 现象 | 先看哪里 |
| --- | --- |
| 面板点「启动」没反应 | 首页日志区；再看「配置」页的 dsh 路径与端口 |
| 检测环境时一直转圈 | 首页日志；多半是 Node 定位失败，点「重新检测」 |
| 面板闪退消失 | `%LOCALAPPDATA%\DshManager\logs`；面板已挂全局异常处理器，崩溃前会记一条 |
| 安装失败 | 用 `/LOG="C:\temp\setup.log"` 重装一次，然后看这个日志 |
| 卸载后数据还在 | 见上面「多个 Windows 用户」的说明 |

面板的全局异常处理会**尽量不让程序退出**：单次操作出错时记日志 + 弹提示，你可以继续用。

## 七、已知限制

1. **桌面快捷方式**：安装包不创建。`[Tasks]` 里的 `desktopicon` 是 `Flags: unchecked`，
   静默安装传 `/MERGETASKS=desktopicon` 实测无效（安装器返回 0 但不建图标）。从开始菜单拖一个即可。
2. **必须管理员权限安装**（只支持机器级安装，避免机器级 / 用户级两套安装互不认识）。
3. **安装向导语言**：简体中文需要有 `ChineseSimplified.isl`；官方 Inno Setup 不带这个文件，
   缺失时向导界面回退英文（页面业务文案仍是中文）。要中文向导就把该文件放到
   `%ProgramFiles(x86)%\Inno Setup 6\Languages\` 后再打包。
4. **不支持 32 位系统**（发布产物是 win-x64）。
5. **面板自己不下崽**：同一时刻只允许运行一个实例，重复启动会把已有窗口提示出来。
